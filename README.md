# メディカル・ローテーション 🩺

スマートフォンのブラウザで遊べる、本格派の医療シミュレーションゲームです。
救急外来に来た患者を、**問診 → 身体診察 → 検査 → 鑑別診断 → 治療 → 経過観察**の流れで診療します。

> ⚠ 本ゲームは医療教育・エンターテインメントを目的としたシミュレーションです。実在の患者の診断・治療には使用しないでください。

## 特徴（MVP）
- **患者は毎回ちがう**：疾患モデルからルールベースで患者を自動生成（年齢・性別・重症度・背景疾患・アレルギー・常用薬・所見がランダム）
- **聞かないと分からない**：選択式の問診、部位×方法（視・触・打・聴）の身体診察
- **検査には費用・時間・侵襲がある**：セット／個別項目、感度・特異度、偽陽性あり
- **鑑別診断は自分で管理**：所見を「支持／否定」に紐づけ、確信度を管理
- **実在薬ベースの処方**：用量・経路・頻度・期間を指定。腎機能・アレルギー・禁忌・相互作用を判定
- **内部状態による経過**：病勢・体液量・血糖・カリウムなどが時間と治療で連動して変化
- **評価**：診断・治療・検査・方針・転帰の5項目。不可避な死亡と回避可能な死亡を区別
- **研修医モード**：★印と解説、指導医への相談、薬剤師の疑義照会、医学ノートで、知識ゼロからでも学びながら上達できる（専攻医・専門医モードでヒントを減らしていく）

## 遊び方
GitHub Pages で公開した URL をスマホのブラウザで開くだけです。ホーム画面に追加するとアプリのように使え、オフラインでも遊べます。
セーブはスマホ本体（ブラウザ）に自動保存されます。

## 公開手順（スマホだけでOK・無料）
1. このリポジトリの `main` ブランチに変更をマージする
2. GitHub の **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. Actions が完了すると `https://<ユーザー名>.github.io/med-game/` で遊べる

## 開発
- 依存ライブラリなし（素の JavaScript / ES Modules）。ビルド不要
- テスト：`npm test`（医学的整合性・データ整合性・経過シミュレーションの自動チェック）
- ローカル確認：`npm run serve` → http://localhost:8080

```
src/
  data/        疾患・問診・診察・検査・薬剤などの構造化データ
    diseases/  疾患モデル（1疾患1ファイル。追加しやすい設計）
  engine/      患者生成・生理モデル・処方評価・経過シミュレーション・採点
  ui/          画面
tests/         自動整合性テスト
docs/          要件定義書
```

疾患を追加するには `src/data/diseases/` に既存ファイルを参考に新しいファイルを作り、`index.js` に登録します。
`npm test` が参照漏れや医学的に不自然な値を検出します。
